## Описание

Реализована численная модель гравитационного взаимодействия N тел в 2D.
Сравниваются два метода расчёта сил:

- **Прямой метод** — попарное суммирование, сложность **O(N²)**.
- **Метод Барнса-Хата** — квадродерево с приближением далёких групп, сложность **O(N log N)**.

Интегрирование по времени — **метод Верле** (2-й порядок точности).

## Запуск

### Основные тесты

```bash
python main.py
```

Создаст 3 графика в `results/`:
- `two_body.png` — орбиты 2 тел (проверка интегратора).
- `disk.png` — вращающийся диск (прямой метод).
- `disk_bh.png` — вращающийся диск (Барнс-Хат).

### Замер времени

```bash
python experiments/timing.py
```

Замеряет время работы обоих методов для N = 100, 300, 500, 1000, 2000.
Сохраняет `results/timing.png` и `results/timing.csv`.

### Замер точности

```bash
python experiments/accuracy.py
```

Замеряет ошибку Барнса-Хата для θ = 0.1, 0.3, 0.5, 0.7, 1.0.
Сохраняет `results/accuracy.png` и `results/accuracy.csv`.

## Результаты

### Ускорение (O(N²) vs O(N log N))

| N    | Прямой (с) | Барнс-Хат (с) | Ускорение |
|------|-----------|---------------|-----------|
| 100  | 0.00267   | 0.00356       | 0.75×     |
| 300  | 0.02420   | 0.01646       | 1.47×     |
| 500  | 0.06784   | 0.03411       | 1.99×     |
| 1000 | 0.27273   | 0.07848       | 3.48×     |
| 2000 | 1.09768   | 0.18163       | 6.04×     |

**Вывод:** при N > 300 Барнс-Хат быстрее прямого метода.
Ускорение растёт с N.

### Точность vs θ

| θ   | Средняя ошибка | Отн. ошибка |
|-----|----------------|-------------|
| 0.1 | 0.00026        | 0.012%      |
| 0.3 | 0.00549        | 0.25%       |
| 0.5 | 0.02071        | 0.95%       |
| 0.7 | 0.05021        | 2.31%       |
| 1.0 | 0.15891        | 7.32%       |

**Вывод:** при θ = 0.5 относительная ошибка < 1%, что является
оптимальным компромиссом между точностью и скоростью.
